# SEEDS Framework
Replication package for the paper: *"From Sustainability Assessment to Decision Records: The SEEDS Framework for Sustainable Requirements Engineering in Digital Health Software"*.

## Overview
The SEEDS framework operationalizes multidimensional sustainability by connecting stakeholder roles to concrete software engineering artifacts (SEEDS-DRs). This repository contains the framework templates, application examples, and the LLM-assisted workflow documentation.

## Repository Structure
- `/templates`: Official SEEDS-DR templates and evaluation rubrics.
- `/examples`: Practical examples of Decision Records across distinct decision contexts (existing systems, solution intake, institutional demands).
- `/llm-poc`: Artifacts for the LLM-assisted generation, including prompt templates, JSON schemas, and sample outputs.
