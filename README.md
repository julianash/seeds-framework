# SEEDS Framework
Replication package for the paper: *"From Sustainability Assessment to Decision Records: The SEEDS Framework for Sustainable Requirements Engineering in Digital Health Software"*.

## Overview
The SEEDS (Sustainability in Biomedical Software Engineering) framework operationalizes multidimensional sustainability by bridging high-level assessment concerns with actionable requirements engineering artifacts. This repository provides the official framework templates, decision record examples, and the LLM-assisted workflow documentation described in our study.

**Visit our official platform:** [https://seeds.ufcspa.edu.br/](https://seeds.ufcspa.edu.br/)
*Use our interactive assessment instrument and visualize sustainability multidimensional results.*

## Repository Structure
- `/templates`: Official SEEDS-DR templates and evaluation rubrics.
- `/examples`: Practical examples of Decision Records (SEEDS-DRs) covering:
    - Existing system assessment
    - Digital health solution intake
    - Institutional software demand formulation
- `/llm-poc`: Artifacts for the LLM-assisted generation, including:
    - `prompt-templates/`: LLM instructions for agentic decision drafting.
    - `json-schema.json`: Structured schema for decision record export.
    - `sample-output.json`: Representative LLM-generated SEEDS-DR draft.
